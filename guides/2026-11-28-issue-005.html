If you still have production workflows sitting inside OpenAI's visual Agent Builder, you have less than 48 hours to get them out.

On November 30, 2026, OpenAI permanently shuts down Agent Builder (its visual drag-and-drop canvas), the hosted Evals dashboard and API (read-only since October 31), and the reusable v1/prompts API. ChatKit stays alive as a frontend UI kit, but every hosted Agent Builder workflow ID stops responding on Monday.

The catch? OpenAI's official export (Code -> Agents SDK) only hands you raw Python or TypeScript boilerplate—not an importable visual graph. And if you blindly rebuild those workflows inside Zapier, its new AI step multipliers can quietly push a 5,000-run agent workflow past $250/month.

Here is the honest 2026 migration math across OpenAI Agents SDK, Zapier, Make.com, and n8n, plus a 15-minute copy-paste blueprint you can import today.

1. What Actually Breaks on November 30, 2026

Before moving a single node, export three assets from your OpenAI dashboard today:

  • Workflow logic (Code -> Agents SDK): Saves your model settings and handoff structure, though app credentials, retries, and webhook plumbing must be rebuilt.
  • Prompt templates & schemas: Copy every system prompt and JSON schema out of v1/prompts before the endpoint retires.
  • ChatKit endpoints: If you embed ChatKit in a product or internal portal, switch it from hosted workflow IDs to your own backend endpoint (Agents SDK, LangGraph, or n8n).

2. The 5,000-Run Migration Cost Verdict

Assume a standard 3-step AI agent workflow running 5,000 times/month: (1) classify & extract JSON -> (2) tool call / lookup -> (3) route & write to Slack or Notion.

Zapier — Fastest Draft, Expensive AI Multipliers

Zapier folded standalone Zapier Agents into AI by Zapier steps—and introduced task multipliers per step: 1x for Standard (no tools), 3x for Advanced (now the default, with tool support), and 5x for Premium reasoning. Zapier MCP calls consume 2x tasks.

  • The 5,000-run math: One 3x classify step + one 5x tool-calling step + one 1x write step = 9 tasks per run. At 5,000 runs/month, that burns 45,000 tasks/month—pushing a solo builder from the 10K Professional tier ($129/mo annual, $193.50 monthly) up into the ~$249–$289/mo (annual) 50K-task range (~$2,988–$3,468/year).
  • The honest con: Task multipliers punish multi-step agent loops fast, and you still have to reconnect every OAuth integration manually.

Make.com + BYO API Key — Best Visual Canvas Parity

If your ops team loved Agent Builder's visual flow, Make.com gives you drag-and-drop routing, Make Grid visibility, and BYO LLM API keys on all paid plans—zero markup on OpenAI, Anthropic, or Gemini tokens.

  • The 5,000-run math: 5,000 × 3 modules = 15,000 credits/month. Core (10K credits) starts at ~$10.59–$12/mo annual; scaling to 20K credits plus ~$10/mo in direct gpt-4o-mini / gemini API calls lands around $22–$30/month total (~$2,700+/year saved vs. Zapier 50K).
  • The honest con: Make still bills per module execution inside array loops—skip an early Filter on a noisy webhook and wasted runs add up fast.

n8n — Best 1:1 Agent + ChatKit Backend

n8n bills per full workflow execution, not per node or AI multiplier—and natively includes AI Agent nodes, MCP Server Triggers, and OpenTelemetry audit tracing.

  • The 5,000-run math: Self-host Community Edition ($0 software) on a 1-click n8n cloud VPS (~$6/mo) + ~$10 direct API usage = ~$16/month. Prefer zero server maintenance? n8n Cloud Starter is $20/mo annual (2,500 executions) and Cloud Pro is $50/mo annual (10,000 executions), totaling ~$60/month with API tokens.
  • The honest con: Self-hosting puts Docker updates and SSL backups on your plate, and Cloud Starter's 2,500-execution cap forces a jump to Pro ($50/mo) once volume grows.

OpenAI Agents SDK + Promptfoo — Best for Pure App Code

  • The 5,000-run math: $0 orchestration license; pay only raw API tokens (~$10/mo) + lightweight hosting ($6–$20/mo). Replace OpenAI Evals with open-source Promptfoo in CI.
  • The honest con: Zero visual debugging or prebuilt SaaS connectors—every Slack, HubSpot, and Notion retry handler lives in your codebase.

3. Copy-Paste Recipe: 15-Minute Agent Builder Replacement Blueprint

Skip rewriting brittle webhook boilerplate. Import this 5-step pattern into Make.com or n8n (you can download both ready-to-import .json files in our Issue #005 Blueprint Guide):

  1. Webhook / ChatKit Trigger: Accept incoming JSON (user_id, message, channel) and validate a shared header secret before touching any LLM.
  2. Guardrail Filter: Reject empty payloads, messages under 12 characters, or bot-originated events immediately so loops cost $0.
  3. Structured Router (BYO API Key): Call gpt-4o-mini or claude-3-5-haiku with strict JSON output (intent, urgency, tool_needed, draft_reply).
  4. Deterministic Tool Branch: Route tool_needed to a real database lookup (Notion or CRM) via standard API nodes—never burn reasoning tokens on static lookups.
  5. Log, Audit & Reply: Write the trace (intent, model, latency) to Notion or OpenTelemetry, return the reply to ChatKit/Slack, and alert a human only when urgency == high.

Result: You replace a dying Agent Builder flow in 15 minutes, cut monthly run costs by 80%–93% vs. multiplied Zapier tasks, and own your prompts and logs permanently.
